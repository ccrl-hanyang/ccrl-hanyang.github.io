CCRL 관리자추가한 내용은 GitHub에 커밋되어 1~2분 뒤 사이트에 반영됩니다

1. 접속

GitHub 토큰이 암호 역할을 합니다. 브라우저에만 저장되며 이 페이지 소스에는 없습니다.

토큰 만드는 법 (한 번만)
GitHub → 우측 상단 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
· Repository access: Only select repositories → 이 저장소만 선택
· Permissions → Repository permissions → Contents: Read and write
· Expiration: 1년 등으로 지정
만들어진 github_pat_... 문자열을 아래에 붙여넣으세요. 유출되면 같은 화면에서 Revoke 하면 즉시 무효화됩니다.

2. 항목 추가

번호와 “전체 N” 은 자동으로 다시 계산됩니다.

3. 구성원 관리

새 구성원은 선택한 그룹의 맨 아래에 추가됩니다 (선배가 위). 사진도 함께 올릴 수 있습니다.

4. 졸업 처리

Students 에서 빼고 Alumni 맨 아래로 옮깁니다. 사진은 그대로 따라갑니다.

5. 표 항목 목록 / 삭제

위 2번에서 “목록 불러오기” 를 누르면 논문·특허·과제·공지 항목이 표시됩니다.

이 페이지는 검색엔진에 노출되지 않도록 설정돼 있습니다. 다만 주소를 아는 사람은 열 수 있으니, 토큰을 공유하지 마세요. 실수로 잘못 올렸을 때는 저장소 History → Revert 로 되돌릴 수 있습니다.
